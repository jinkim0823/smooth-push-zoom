# Attribution

Smooth Push Zoom builds on the modifier-scroll event capture and native GNOME
magnifier approach of **Deperto**, by **Dennis Guimarães**.

- Original project: https://github.com/dennisguim/deperto
- Upstream license: https://github.com/dennisguim/deperto/blob/main/LICENSE

Changes include proportional zoom steps, frame-based interpolation, preserving
GNOME's selected mouse tracking, cursor-anchored zoom, external settings
synchronization, paired-scroll deduplication, optional pointer refresh, and
installation and regression tests. This project is independently maintained;
