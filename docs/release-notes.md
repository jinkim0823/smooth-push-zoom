# Smooth Push Zoom 0.1.0-rc.1

First release candidate for smooth, cursor-anchored desktop zoom on GNOME 46.
Hold Super + Alt and scroll; preserve GNOME's Pushes Contents Around tracking,
and zoom out to 1.00× to turn Desktop Zoom off.

Includes configurable shortcuts, speed, smoothing and maximum zoom; external
zoom synchronization; paired scroll handling; and optional responsive pointer
tracking. GNOME 51 is available as a separate experimental preview.

Verified with automated behavior checks, package/installer checks, a real GNOME
46 isolated compositor session and actual preferences widgets. Physical device
feel, multi-monitor setups, session transitions and GNOME 51 runtime behavior
need further testing. Please report your GNOME version, session type, display
configuration and reproduction steps with any issues.

For installation, download the extension ZIP asset, not the GitHub source ZIP.
